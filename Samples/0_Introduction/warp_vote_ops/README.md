# warp_vote_ops - Simple Vote Intrinsics

## Description

A simple program demonstrating how to use vote intrinsics (__any_sync, __all_sync) in HGGC kernels.

## Key Concepts

Vote Intrinsics.

## Supported Operating Systems

Linux

## Supported CPU Architectures

x86_64

## Supported PPU Architectures

ppu001, ppu0015

## HGGC APIs Involved

### HGGC Runtime API
hggcMemcpy, hggcFree, hggcDeviceSynchronize, hggcMalloc, hggcGetDeviceProperties

## Prerequisites
Please download and install the T-Head SAIL toolkit for your platform.
