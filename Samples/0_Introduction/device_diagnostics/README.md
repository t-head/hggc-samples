# device_diagnostics - Device-Side Diagnostic Output

## Description

This sample is a basic HGGC Runtime API example that demonstrates how to use the printf function in device code.

## Key Concepts

Debugging.

## Supported Operating Systems

Linux

## Supported CPU Architectures

x86_64

## Supported PPU Architectures

ppu001, ppu0015

## HGGC APIs Involved

### HGGC Runtime API
hggcGetDeviceProperties, hggcDeviceSynchronize, hggcGetDevice

## Prerequisites
Please download and install the T-Head SAIL toolkit for your platform.
