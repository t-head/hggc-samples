# fp16_dot_product - FP16 Scalar Product

## Description

Computes the scalar product (dot product) of two FP16 numerical vectors.

## Key Concepts

HGGC Runtime API.

## Supported Operating Systems

Linux

## Supported CPU Architectures

x86_64

## Supported PPU Architectures

ppu001, ppu0015

## HGGC APIs Involved

### HGGC Runtime API
hggcMemcpy, hggcFree, hggcMallocHost, hggcFreeHost, hggcMalloc, hggcGetDeviceProperties

## Dependencies for Build/Run
FP16

## Prerequisites
Please download and install the T-Head SAIL toolkit for your platform.
